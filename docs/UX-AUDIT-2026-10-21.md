# Hands-on UX audit, 2026-10-21

A first-time-user test of every function, done by hand in a real browser (Playwright Chromium) at desktop 1440x900, iPhone 15 and Pixel 7. Stores scanned were local fake stores on my own ports (good Shopify, bad Shopify, good WooCommerce, a broken store that answers 500, a store too slow to answer, and a port with nothing listening). No real third-party sites were scanned. The $299 path was tested with no key (real 503) and with a fake test key plus a mocked Stripe API; the Stripe checkout page itself was a local stub, so nothing touched Stripe.

Devices: D = desktop 1440x900, i = iPhone 15, P = Pixel 7. Screenshots are in `evidence/ux-audit-2026-10-21/` (`-after` = re-test after the fix). Every screenshot was opened and looked at.

Result: 30 functions tested. 25 work, 1 broken (fixed), 3 confusing (product choices, left for Rowan), 1 not testable.

## Suggestions for Rowan (product choices, not changed)

1. **No-key payment state (#15).** Today a visitor sees a live-looking "Fix it for me" button with "Payments are not set up yet (test mode not configured)." Options: hide the offer until payments work, grey out the button, or swap it for a "Get in touch" link. The wording "test mode not configured" is engineer language for a store owner.
2. **Keep the result (#19, #20).** Put the store in the URL (for example `?store=mystore.com`) so refresh, Back and "send this to my developer" all work.
3. **Slow-store message (#11).** "We could not reach that store" also shows when the store is just slow; "Your store took too long to answer" would be more accurate.
4. **Test-mode notice on a live page.** "Payment runs through Stripe in test mode only" is right for now but must be reworded before real launch.

## Not testable and why

- **#30 Real Stripe hosted checkout page.** Needs a real Stripe test key and a call to Stripe's servers; this audit was not allowed to contact third-party sites. The app's own side (button, request body, test-mode guard, redirect, return pages) was tested with a mocked Stripe API. Commit e98ebfd (BLOCKERS.md) records an earlier real Stripe test-mode run; not re-checked here.
